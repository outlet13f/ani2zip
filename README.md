# EpiGrab

[yt-dlp](https://github.com/yt-dlp/yt-dlp) 기반 동영상/재생목록 다운로더입니다. GUI(대기열)와 CLI를 모두 제공합니다.

yt-dlp 가 지원하지 않는 사이트라도 페이지 HTML 에서 미디어 링크(HLS·DASH·MP4 등)를 직접 찾아 시도하고,
영상 없이 회차 목록만 있는 페이지라면 각 회차 페이지를 순서대로 받습니다.

## 주요 기능

- **yt-dlp 지원 사이트**: 단일 영상과 재생목록을 다운로드합니다.
- **미지원 사이트 테스트 모드**: yt-dlp 가 실패하면 페이지의 HTML/JS 에서 `m3u8`, `mpd`, `mp4` 등 미디어 링크와 임베드 플레이어(iframe, 한 단계까지)를 탐색해 HLS → DASH → 비디오 파일 순으로 시도합니다. 링크를 찾은 페이지를 Referer 헤더로 붙여 요청합니다.
- **회차 목록 자동 처리**: 현재 경로 아래의 링크(예: `/anime/123` → `/anime/123/1`, `/anime/123/2` …)를 회차로 보고 번호 순으로 모두 받습니다.
- **자막**: 사이트가 제공하는 자막이나 페이지에서 찾은 별도 자막 파일(`vtt`, `srt`, `ass`, `ssa`, `smi`)을 영상과 같은 이름으로 저장합니다. 팟플레이어나 VLC 가 자동으로 불러옵니다.
- **작품 제목 폴더**: 페이지 제목에서 사이트 이름과 회차 표기를 걷어 내고 `저장 폴더\작품 제목\작품 제목 1화.mp4` 형태로 정리합니다.
- **화질 제한**: 2160p ~ 360p 중 고른 화질 이하에서 가장 높은 화질을 받습니다. 해당 화질 이하가 없으면 가장 가까운 화질을 받습니다.
- **오디오 전용**: MP3(192kbps)로 음원만 추출합니다.
- **동시 조각 수**: HLS/DASH 조각을 여러 개 동시에 받습니다. 서버의 연결당 속도가 낮을 때 올리면 빨라지지만, 너무 높이면 사이트에서 차단될 수 있습니다.
- **분석 모드**: 다운로드하지 않고 yt-dlp 지원 여부, 미디어 후보, 저장될 이름을 미리 확인합니다.

## 요구 사항

- Python 3.10 이상 (GUI 를 쓰려면 tkinter 포함)
- [FFmpeg](https://ffmpeg.org/) — `PATH` 에 등록되어 있어야 합니다. 비디오·오디오 병합과 MP3 변환에 필요합니다.
- Python 패키지

  ```bash
  pip install -r requirements.txt
  ```

  `pycryptodomex` 는 암호화된(AES-128) HLS 복호화를 빠르게 해 줍니다. 없어도 동작하지만 매우 느려집니다.

## 사용법

### GUI

`EpiGrab.bat` 을 더블클릭하거나 다음을 실행합니다.

```bash
python gui.py
```

1. **URL** 을 입력하고 **대기열 추가**를 누릅니다. 클립보드에 URL 이 여러 개 있으면 **붙여넣기** 한 번으로 모두 추가됩니다.
2. 저장 폴더와 다운로드 옵션을 고릅니다. 옵션은 대기열에 추가하는 시점의 값이 항목별로 저장됩니다. **동시 조각 수**만 전체 설정이라 진행 중에 바꿔도 다음 회차부터 적용됩니다.
3. **대기열 다운로드 시작**을 누릅니다.

대기열에서는 항목 순서 변경, 실패한 항목 다시 시도, 선택 삭제, 완료 항목 정리를 할 수 있습니다.
**중지**하거나 프로그램을 닫아도 대기열이 저장되어, 다음에 시작하면 받던 파일부터 이어서 받습니다.

**분석만 하기 (테스트)** 는 URL 입력창이 비어 있으면 대기열에서 선택한 항목을 분석합니다.

### CLI

```bash
python downloader.py [URL] [옵션]
```

URL 을 생략하면 실행 후 입력받습니다.

| 옵션 | 설명 |
| --- | --- |
| `-o`, `--output DIR` | 저장 폴더 (기본값: `downloads`) |
| `-a`, `--audio-only` | MP3 음원만 추출 |
| `-q`, `--quality P` | 최대 화질: `2160`, `1440`, `1080`, `720`, `480`, `360` (기본값: 최고 화질) |
| `-N`, `--concurrent-fragments N` | 동시에 받을 조각 수 (기본값: 4) |
| `--analyze` | 다운로드 없이 지원 여부와 미디어 후보만 확인 |
| `--no-fallback` | yt-dlp 미지원 시 페이지 직접 탐색을 하지 않음 |
| `--no-subs` | 별도 자막 파일을 받지 않음 |
| `--no-folder` | 작품 제목 폴더 없이 저장 폴더에 바로 저장 |

```bash
# 720p 이하로, 조각 16개씩 동시에 받기
python downloader.py "https://example.com/anime/123" -o D:\Downloads\ani -q 720 -N 16

# 받기 전에 어떻게 처리될지 확인
python downloader.py "https://example.com/anime/123" --analyze
```

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `downloader.py` | 다운로드·페이지 탐색 로직과 CLI |
| `gui.py` | tkinter GUI (대기열, 진행률, 로그) |
| `EpiGrab.bat` | Windows 에서 GUI 를 실행하는 배치 파일 |
| `settings.json` | GUI 설정(마지막 저장 폴더, 화질, 동시 조각 수). 실행 시 자동 생성 |
| `queue.json` | GUI 대기열. 실행 시 자동 생성 |

`settings.json`, `queue.json`, `downloads/` 는 사용자별 파일이라 저장소에 포함하지 않습니다.
